# Folder: history

1. **地位**: 运行历史页面。通过日历热力图展示半年内模型运行记录的风险趋势，点击日期查看触发规则、告警信息和运行元数据。
2. **逻辑**: 页面加载 → 调用 `apiClient.getHistory(180)` 获取半年数据 → `CalendarHeatmap` 按 risk_light 着色展示 → 用户点击日期 → 调用 `apiClient.getOutputById()` 加载详情 → 渲染规则表格、告警列表和运行信息摘要。
3. **约束**: 日历热力图数据来源于 HistoryRecord 的 risk_light 字段；详情展示依赖 ModelOutput 完整结构。

- `page.tsx`: 运行历史页面组件 (Page Component) — 路由 /history
