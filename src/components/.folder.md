# Folder: components

1. **地位**: UI 组件层。存放所有可复用的 React 展示组件，负责纯 UI 渲染，不包含业务状态管理。
2. **逻辑**: 接收由页面组件 (app/) 传入的 props（数据、回调函数）→ 渲染对应的 UI 结构 → 通过回调通知父组件用户操作。
3. **约束**: 组件必须是纯展示型，不直接调用 API；状态管理仅限 UI 级别（如输入框值、加载态）；所有组件均标记为 `"use client"`。

## 成员清单

- `Sidebar.tsx`: 左侧导航栏 (Navigation) — 固定布局，路由链接 + 系统状态指示
- `Header.tsx`: 顶部工具栏 (Toolbar) — 日期选择器 + 运行模型按钮 + 最后更新时间
- `MetricCard.tsx`: 指标卡片 (Data Display) — 单个数值指标的卡片式展示
- `GateCard.tsx`: 闸门卡片 (Data Display) — 门控状态可视化，含进度条和状态指示器
- `Chart.tsx`: 通用图表 (Data Visualization) — 基于 Recharts，支持面积图/折线图 + 参考线
- `CalendarHeatmap.tsx`: 日历热力图 (Data Visualization) — 月历视图，按 risk_light 颜色着色，含月份导航、图例和月度统计
- `DatePicker.tsx`: 日期选择器 (Input Control) — 点击展开的日历面板，有数据日期 cyan 圆点标记
- `providers.tsx`: 全局 Provider (Context Wrapper) — React Query 客户端配置与注入
- `SignalOverlayChart.tsx`: 回测信号叠加图组件 (Data Visualization) — SPX价格折线 + 风险灯号背景色带 + 宏观状态标注
- `BacktestPanel.tsx`: 回测面板组件 (Composite) — 可嵌入的完整回测 UI：参数面板 + 统计卡片 + 信号图 + 明细表 + 变更时间线，支持 combined/liquidity/macro/equity/btc 五种模型模式
- `ChartPane.tsx`: Charts Workspace 单 pane 组件 (Data Visualization) — 基于 lightweight-charts v5，支持多 series 叠加 + 十字线 + Clinical Dark 主题；被 EditablePane 引用，不发起 API 请求（pure presentational）
- `EditablePane.tsx`: 可编辑 pane 包装器 (Composite) — title bar + series chips（含 ✕ 移除）+ ChartPane canvas；missing symbols 用 amber 标记
- `IndicatorSearchModal.tsx`: 指标搜索 modal (Composite) — 搜索 catalog 104+ indicators，按 model_module 分组，feature/raw 类型 badge 区分，支持连续批量添加
- `ChartsToolbar.tsx`: Charts Workspace 顶部工具栏 (Composite) — preset 切换 + 时间区间（1M-ALL）+ Transform（原始/归一化/%变化）+ As Of vintage 回放 + EventsSelector + 添加 Pane / 复制 URL / 重置
- `EventsSelector.tsx`: 事件类型多选 popover (M5) — 列出 catalog 9 类事件，复选框勾选 + 全选/推荐/全清快捷键；空选 = 不显示任何 markers
